# Architecture Decision Records

This folder holds the record of significant technical choices made on this project. Each file follows the [`_template.md`](./_template.md) format. Files are **immutable** once accepted — if a decision is reversed, we mark the old ADR `Superseded by NNNN` and write a new one.

## How to read an ADR

Every ADR opens with an **In plain English** section. Read that first. If you want the engineering detail, the rest of the file has it.

## How to add one

1. Copy `_template.md` to a new file: `NNNN-short-title.md` (next number, kebab-case).
2. Fill in every section.
3. Add a row to the index below.
4. Link to it from the relevant architecture file under `docs/architecture/`.
